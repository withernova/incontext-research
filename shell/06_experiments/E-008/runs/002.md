## 1. 研究设计
### 研究问题
在自然 bbox token 的 exact teacher replay 中，若只置换 target query heads 在 query-image visual-token span 内的原 attention 值、而不改变该 span 总质量或权重分布，bbox-token 预测会否改变？
### 本轮目的
比较原 attention、identity 重写与 query-span 内位置置换，检验模型是否依赖 query 图像中“哪个 token 获得哪个 attention 权重”的空间对应关系，而不是只依赖 query-image 总 attention 预算。该比较不改 reference span，排除把 Q→R 路由变化误当成 query-image 内部空间效应。
### 假设或比较预期
若 query-image 内空间位置—权重对应对 bbox token 重要，query_permuted 相对 identity/baseline 应改变 natural bbox token NLL 与 logits；若主要只依赖 query-image 总预算或下游对该细粒度布局不敏感，置换效应应接近 identity。
### 数据与主要变量
复用 E003-R-004b positive n140 manifest 与归档 natural responses；primary 仅采用可唯一匹配归档 response、双图 span 和 natural bbox token p-1 rows 的 accepted error35+correct76=n111。partial/rejected 只报告对齐覆盖，不因结果补样本；样本、head、row 均在查看干预结果前固定。

干预层级=attention probability representation，在 softmax 后、dropout 前、A@V 前。target heads 固定 L18H15,L19H03,L22H00,L20H08；每个 exact bbox p-1 row 独立处理。条件为 baseline（无 hook）、identity（原 query-span 值原位写回）和 query_permuted（仅对 query visual span 的原值作确定性一一置换）。reference visual span、文本、其他 token、target V 与 Q→R attention 全部保持原样；不重采样、不归一化、不改变 query-span mass。

## 2. 指标设计
复用 exact_replay_rate 作为行/span 对齐门禁；主指标为每样本自然 bbox token mean NLL 相对 baseline 的配对差和 selected bbox-token logits 最大绝对差。辅助记录 query-image span 的 raw attention entropy、sorted-value max difference、query-span mass error、整行和误差、A@V L2/cosine change；不复用 GT attention 空间质量指标作为干预选择或主结论。
### Exact teacher-replay通过率 (`exact_replay_rate`)
- 公式：N_exact / N_total
- 含义：归档响应token、bbox p-1 row与双图span均精确对齐的样本比例
- 汇总与范围：micro ratio / R-000工程门禁与R-001完整性

### GT区域fractional attention mass (`fractional_gt_mass`)
- 公式：sum_j A_j * w_j，其中w_j为视觉token与GT bbox的fractional occupancy
- 含义：指定row/head在目标区域内分配的raw attention质量
- 汇总与范围：逐head样本中位数及sequence bootstrap / Q→Q[G]、Q→R[G]、G→R[G]、Q→Q[L]

### GT区域面积归一化富集 (`area_normalized_enrichment`)
- 公式：(sum_j A_j*w_j / sum_j A_j) / (sum_j w_j / N_visual)
- 含义：相对均匀视觉attention时目标区域获得的富集倍数
- 汇总与范围：逐head样本中位数及correct-error差 / 各视觉span内条件化attention

### Raw-attention pointing命中率 (`pointing_rate`)
- 公式：N[argmax_j A_j的token与GT bbox有fractional overlap] / N_eligible
- 含义：raw map峰值是否落入目标区域的样本比例
- 汇总与范围：逐head分子/分母、Wilson区间与sequence bootstrap差 / GT覆盖至少一个merged visual token的样本

### 累计质量fractional-token IoU AUC (`retained_mass_fiou_auc`)
- 公式：mean_{rho in {0.05,...,0.95}} fIoU(S_rho,GT)，S_rho为达到累计attention质量rho的最小token集合
- 含义：衡量distributed attention support与GT token区域在多阈值下的空间重合
- 汇总与范围：逐head样本中位数及sequence bootstrap / 各预注册edge的视觉span条件化raw attention
