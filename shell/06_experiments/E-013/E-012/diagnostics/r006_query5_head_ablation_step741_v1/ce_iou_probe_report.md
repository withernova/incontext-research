## 判断

1. **选头分数确实主要在追踪 CE 敏感度**（score↔|ΔCE| +0.66），**与 IoU 之间几乎无对应**（↔ΔIoU −0.21；|ΔCE|↔ΔIoU −0.15）。担心成立。
2. **象限 B（ΔCE 大、ΔIoU≈0）确实存在**：`L17H04` 是单头里 |ΔCE| 最大者（0.062），ΔIoU 只有 −0.017（CI 跨 0）；三组**随机 5 头**的 |ΔCE| 可达 0.061，ΔIoU 却只有 −0.007~−0.026。也就是说 ΔCE 既不特异于被选中的 head，也不预测 IoU 损害。
3. **象限 C（ΔCE 极小、ΔIoU 为负）也有候选**：rank 80 的 `L26H27`（|ΔCE|=0.002，ΔIoU −0.030）与 rank 640 的 `L05H29`（|ΔCE|=0.001，ΔIoU −0.025）——但两者 CI 都跨 0，且见下面的噪声问题，暂不能当证据。
4. **17 头联合干预把 mIoU 打掉 −0.237**（ΔCE 仅 +0.243），说明"高名次 head 集合"整体确实承重；但**缺同层随机 17 头对照**，不能把该下降归因于选头特异性（对比：3 组随机 5 头只有 −0.007~−0.026）。

## 一个更硬的方法论问题：IoU 轴本身有运行间噪声

三次 step741 消融（今天先后跑）的 baseline 对比：

| 对比 | 逐样本 ΔIoU 均值 | 逐样本 std | mean\|ΔIoU\| | 逐样本 teacher-forced ΔCE |
|---|---:|---:|---:|---:|
| A(r006q5) vs B(legacy5) | −0.0017 | 0.036 | 0.021 | std = **0.0000** |
| A vs C(probe) | −0.0137 | 0.128 | 0.036 | std = **0.0000** |
| B vs C | −0.0120 | 0.131 | 0.044 | std = **0.0000** |

- **teacher-forced CE 三次逐样本完全一致**（无任何差异），说明前向是确定性的。
- **自然生成不是**：60 条样本只有 1 条出现 >0.2 的 IoU 抖动（idx=21：A/B 得 0.000，C 得 0.953），但 60 条里 0/60 生成文本相同，逐样本 |ΔIoU| 平均 0.021–0.044。
- 直接后果：**同一个单头干预在不同 run 给出相反符号**——`L23H30` 在 run A 是 **+0.0292**（CI [−0.0235,+0.0896]），在 run C 是 **−0.0214**（CI [−0.0487,−0.0021]）；`L21H11` 是 +0.0318 vs −0.0226。剔除那 1 条抖动样本后结论不变（+0.014 vs −0.022）。
- 所以：**单头 ΔIoU 在 n=60 下低于噪声底线，散点图的 y 轴不可靠**；只有大幅效应（旧 5 头 −0.164、17 头联合 −0.237）远超噪声，可以下结论。

## 结论与下一步

- 用户的判断（token-CE objective 与 geometry objective 错位）**有实验支持**：screening 分数预测 CE 敏感度、几乎不预测 IoU；随机 head 也能制造同量级 ΔCE。
- 但**不能据此直接宣布"选头无效"**，因为承担结论的 IoU 轴在单头尺度上噪声过大；要让散点结论站得住，必须先修 IoU 轴：
  1. 对同一条件重复生成（例如同 config 重复 3 次、或改多 seed/temperature 采样取平均），把 ΔIoU 的噪声压到单头效应以下；
  2. 加**同层随机 17 头对照**，检验 17 头联合 −0.237 是否为选头特异；
  3. 之后再考虑引入可微 geometry surrogate（软坐标目标 `q(k) ∝ exp(−|k−y|/τ)`）作为第二个贡献量 `I_geom`，并比较 `G_CE` 与 `G_geom`。

## 修正与边界

- `inputs/ce_iou_probe_heads_v1.json` 里的 `source_sha256` 字段误写为 `0fd30062…`（那是另一次消融 summary 的 hash）；R-006 screening `summary.json` 的正确 sha256 是 **`f20dc8e994b633710c16c2a113998e168fface6f2ff68dfbd1ff4849a58577fc`**。head 的 layer/head 数值本身经复算无误，该字段只影响溯源说明；文件已按旧 sha 冻结进本次 run，不再改动。
- screening 在 step247 上做，本消融在 step741 上跑，名次可能漂移；单头 ΔIoU 的 CI 为样本 bootstrap，不含运行间生成噪声。
- 整头置零是粗干预：它同时移除这些 head 的文本/其他边，而 screening 的 C 只关于 bbox 行→query 视觉边。
