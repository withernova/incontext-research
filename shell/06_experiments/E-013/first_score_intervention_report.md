# E-013 首框分数改写后的第二框续写

日期：2026-09-29。探索性诊断，不修改 Experiment、Run、Claim 或审批状态。

## 输入与干预

使用 E-013 训练分支 `20260928T170859Z--multi3-instances-grpo-rank-cf-lr8e5-3ep` 的 step 450 policy adapter。其 SHA-256 为 `b1fbe4ded81ce7e186bf9574e5d2613c4037a270956ebf9fabae05875b27a884`，与现有 step 450 评测兼容 adapter 的哈希一致。按[固定口径](first_score_intervention_protocol.md)从该分支 step 400–445 的 rollout 选出 [6 条首框错选记录](first_score_intervention_cases.json)：原输出中首框分数最高，但第二框 IoU 唯一最高且至少比首框高 0.1。

对每条记录保留相同图像、提示和第一框文本；把第一框 score 分别设为**原值、0.01、0.99**，贪心续写。主观察让模型自行生成第二框和分数；辅助观察固定原记录中的第二框文本，只续写其分数。三条件共用同一视觉张量，分数文本可无损回解码。没有训练、逐 step 评测或第三框选框测试。

## 自由生成第二框：逐例结果

下表的“原值”也是 step 450 模型的**新续写**，并非先前训练 rollout 保存的第二框 score。IoU 是新生成第二框相对于目标的 IoU。

| rollout step / 样本前缀 | 首框原 score | 第二框 score：原值 / 0.01 / 0.99 | 第二框 IoU：原值 → 0.01 |
| --- | ---: | ---: | ---: |
| 412 / `63c28a9d` | 0.86 | 0.72 / **0.87** / 0.97 | 0.890 → 0.877 |
| 419 / `fcf6a13e` | 0.83 | 0.08 / **0.01** / 0.01 | 0.166 → 0.192 |
| 435 / `d69ba511` | 0.67 | 0.08 / **0.00** / 0.00 | 0.723 → 0.716 |
| 441 / `5a53dc4c` | 0.85 | 0.08 / **0.01** / 0.01 | 0.846 → 0.861 |
| 444 / `618d8019` | 0.97 | 0.01 / **0.01** / 0.01 | 0.914 → 0.914 |
| 445 / `055a99e4` | 0.95 | 0.07 / **0.98** / 0.01 | 0.926 → 0.926 |

把首框 score 降到 0.01 后，第二框 score 相对原值条件 **2 例升高、3 例降低、1 例不变**。第二框严格高于被改写的首框只有 **2/6**；另有 3 例相等、1 例更低。第二框 IoU 的逐例变化均在 ±0.026 内，说明这六例主要变化在分数，生成框的位置变化较小。第 419 例的自由生成第二框 IoU 低于原记录的第二框 IoU，因此不能假定每次重续写仍保持原记录的候选质量排序。

辅助的“固定第二框文本、只续写分数”给出相同的六例变化方向（上升 2、下降 3、不变 1）。两套完整逐例结果分别在[自由生成数据](first_score_free_second_results.json)和[固定第二框数据](first_score_intervention_results.json)。18/18 次自由生成及 18/18 次固定框续写均得到可解析的第二框分数。

## 结论边界

这组小样本说明：第一框 score 文本确实可能影响后续第二框 score，但**降低第一框分数并不会稳定地提高第二框分数**；部分样本反而把第二框分数一起压低。该结果来自刻意选取的六条晚期训练 rollout 和同一个 step 450 checkpoint，不能估计总体效应。实验在第二框分数结束处停止，没有生成或比较第三框，因此不能由此断言最终三框选择率会提高。
