## 实验目标
在**当前已经训练完成的 IPLoc-ID 模型及其真实双图任务**上，直接验证 LocalizationHeads 式“少数固定 attention heads 可用于视觉定位”的方法是否可靠，而不是复现原论文的 RefCOCO 数值，也不是只在单次样本集合上偶然成立：

1. **换数据后是否稳定**：更换用于挑选注意力头的图片、随机顺序或样本组成后，是否仍选出相近的头；
2. **是否覆盖多数图片**：固定的头是否对大多数图片有效，而不是由少数容易图片撑高平均结果；
3. **是否真的看向物体**：入选的头是否偏向真实物体区域，而不只是看图像边缘、中心或固定位置；
4. **是否适用于没参与挑选的样本**：在新的视频序列、物体身份、答对和答错样本中是否保持效果；
5. **结论是否说过头**：严格区分“热图中能看出物体位置”和“模型完成任务必须依赖这些头”。

需要先纠正一个关键理解：论文不是给每张图永久保留一组不同的头。它先在每张图中找出“注意力集中在少数位置”的候选头，再统计哪些头在很多图片中经常出现，最后固定使用出现次数最多的 3 个或 5 个头。论文还报告，固定一组头比每张图临时挑头更好。逐图候选不同本身不是反例；真正需要检查的是，换一批图片后最终固定的名单是否稳定，以及这份名单是否能覆盖多数新图片。[[localizationheads2025]] §4.1–4.2、§6.3

## 我们预期看到什么
- 换一批用于挑选注意力头的图片后，仍会反复找到一批相近的头。
- 这些头一旦选定，在未参与选择的图片上仍能找到真实物体。
- 有效结果应出现在多数图片上，而不是由少数大物体或容易图片拉高平均分。
- 参考图、待查图和不同输出时刻可以需要不同的头，但每一种用途内部都必须稳定。
- 热区应随真实物体移动，并对参考物体身份改变作出反应，而不是只看固定坐标或显眼背景。
- 前八个实验只能说明“从这些头的注意力中可以看出物体位置”；只有实验 9 才能检查模型是否真的依赖这些头。

## 整体成功条件
- 实验 1 的位置对应检查全部通过。
- 实验 2 证明换数据后仍能找到相近的头，而且相似程度明显高于随机挑选。
- 实验 3 和 4 证明事先固定的头在新图片和大多数样本上确实能找到物体。
- 实验 5 证明这种现象与模型实际答对有关系，而不只是热图好看。
- 实验 6 清楚说明参考图和待查图是共用一批头还是各用一批头。
- 实验 7 和 8 排除“只看显眼物体”“复制坐标”和“固定位置”这些简单解释。
- 所有失败样本、无法解析的答案和位置对应错误都必须计入结果，不能悄悄删除。

## 整体失败条件
出现以下任一情况，都不能说固定少数注意力头在 IPLoc-ID 上可靠：

- 换一批图片后，选出的头几乎完全改变；
- 固定头在新图片上不比随机头好；
- 只有每张图片临时重选最有利的头才能得到好结果；
- 平均结果不错，但大多数图片失败；
- 热区不随物体移动，或换错参考身份后完全不变；
- 参考图、待查图或文字位置没有正确对应；
- 只有热图证据，却直接声称这些头是模型完成任务的必要原因。

## 实验安排

下面的“注意力头”是指模型内部一个独立计算“当前文字位置主要看向哪些图像位置”的小单元。这里列出的 9 个“实验”是 9 个需要分别回答的问题，**不是 9 个需要单独审批的 Run**。实际执行合并为 2 个 Run，见后文“如何合并执行”一节。

### 实验 1：先确认我们读取的位置没有错
**要回答的问题：** 我们画出的注意力图，是否真的对应 IPLoc-ID 模型在输出答案时使用的图像位置？

**使用什么数据：** 少量已有 IPLoc-ID 样本，包含参考图、待查图、真实物体框和模型自然生成的答案。

**具体做法：**
1. 明确区分参考图和待查图在模型输入中的图像小块位置。
2. 分别读取三个时刻的注意力：模型看完问题时、模型准备输出物体框坐标时、模型准备回答“是/否”时。
3. 将每个注意力头看到的图像小块重新画回原图。
4. 检查同一个输入重复运行时，图像位置、文字位置和注意力图是否完全一致。

**通过条件：** 所有样本都能明确对应到正确的参考图、待查图和文字位置；重复运行结果一致；不存在空图、错位或把参考图当成待查图的情况。

**失败后怎么办：** 停止后续实验，先修正位置对应关系。位置没对齐时产生的任何热图都不能解释。

### 实验 2：换一批图片后，还会不会找到同一批注意力头
**要回答的问题：** 所谓“重要的少数注意力头”是否稳定，还是每换一批图片就完全不同？

**使用什么数据：** 将 IPLoc-ID 样本按视频序列或物体身份分组。同一序列的图片不能同时出现在“找头用的数据”和“检查结果用的数据”中。

**具体做法：**
1. 多次更换“找头用的数据”，每次独立运行论文的选择方法。
2. 每次都记录所有注意力头被选中的次数，而不只记录前三名或前五名。
3. 比较各次结果：完全相同的头有多少、排名是否接近、某个头是否只靠少数图片才进入前列。
4. 再逐组移除某一类物体、某个视频序列或某种大小的物体，检查结果是否被某一小组数据控制。

**对照：** 随机选择相同数量、且来自相近模型层数的注意力头。

**通过条件：** 不同数据分组下反复出现的注意力头明显多于随机选择；主要注意力头不是由极少数图片或单一视频序列决定。

**失败意味着什么：** IPLoc-ID 上不存在可靠的固定少数头。此时可以报告“每张图可能需要不同的头”，但不能继续用一组固定头代表整个任务。

### 实验 3：固定注意力头后，在没参与选择的图片上是否仍能找到物体
**要回答的问题：** 实验 2 找到的固定注意力头，能否真正用于新一批 IPLoc-ID 图片，而不是只记住用于选择它们的图片？

**使用什么数据：** 实验 2 中从未用于选择注意力头的序列或物体身份。

**具体做法：**
1. 在查看这批图片结果之前，固定注意力头、头的数量和生成热图的方法，之后不再修改。
2. 分别在参考图和待查图上画热图。
3. 检查热图最强位置是否落在真实物体框内。
4. 检查真实物体框内获得的注意力是否高于同样大小的背景区域。
5. 将多个固定注意力头合成一个物体框，再与真实框比较重合程度。

**对照：** 随机注意力头、只选择“经常看图”的头、只选择“热图比较集中”的头、所有头平均，以及每张图片临时挑选最有利的头。

**通过条件：** 事先固定的头在未参与选择的图片上稳定优于上述对照，而且不是只有极少数图片表现很好。

**失败意味着什么：** 选择次数高不等于能可靠定位物体；不能把这些头称为 IPLoc-ID 的定位头。

### 实验 4：是不是只有少数容易图片撑高了平均结果
**要回答的问题：** 固定注意力头是否对大多数图片都有效？

**使用什么数据：** 实验 3 的全部图片，不新增选择或重新挑头。

**具体做法：**
1. 逐张报告：有几个固定头看到了真实物体、合成热图是否找到物体、预测框与真实框重合多少。
2. 分别统计小物体、大物体、遮挡物体、多实例图片和不同视频序列。
3. 报告最差的一组，而不只报告所有图片的平均值。

**通过条件：** 多数图片方向一致，各主要分组都没有大面积失败。

**失败意味着什么：** 即使总平均值不错，也只能说方法适用于某些容易图片，不能说固定少数头普遍可靠。

### 实验 5：模型答对和答错时，注意力头有什么区别
**要回答的问题：** 这些注意力头是否与 IPLoc-ID 的实际定位成功有关？

**使用什么数据：** 模型原本自然生成的答案。先按最终物体框是否正确分成“答对”和“答错”，再读取对应注意力；不允许用真实框替换模型答案后重新定义答对。

**具体做法：**
1. 对每个自然生成答案，重新运行一次完全相同的输入并读取注意力。
2. 分别比较答对与答错样本中，固定头看向真实物体的程度。
3. 同时报告参考图和待查图，不能只挑差异最大的一边。
4. 正样本和负样本分开报告，避免“是否同一物体”和“框是否正确”混在一起。

**通过条件：** 固定头在答对样本中更一致地看向正确区域，而且差异不是由物体大小或某几个视频序列造成。

**失败意味着什么：** 即使热图看起来像物体，也未显示它与模型实际答对有关；只能称为图像中的可读信号。

### 实验 6：参考图和待查图是否需要不同的注意力头
**要回答的问题：** 模型看参考物体和在待查图中定位物体时，是否由同一批注意力头完成？

**使用什么数据：** 与实验 2、3 相同的数据划分，但参考图和待查图始终分开计算。

**具体做法：**
1. 单独寻找“看参考图真实物体”的头。
2. 单独寻找“看待查图真实物体”的头。
3. 交换评估：用参考图选出的头去检查待查图，用待查图选出的头去检查参考图。
4. 对每个头逐一检查真实物体区域，不能只比较两组名单是否有相同编号。

**通过条件：** 无论最终是一组共同的头还是两组不同的头，各自在重复选取和未见图片上都稳定有效。

**失败意味着什么：** 如果头的编号偶尔相同但并不看向真实物体，不能称为共同定位头；如果两边需要不同的头，也不能把它们强行平均成一组。

### 实验 7：换错参考物体后，注意力是否真的会改变
**要回答的问题：** 注意力头是在使用参考物体的身份信息，还是只看待查图中最显眼的同类物体？

**使用什么数据：** 同一张待查图，配正确参考图和同类别但不同身份的参考图。

**具体做法：**
1. 保持待查图和问题格式不变，只替换参考图中的物体身份。
2. 比较模型答案是否改变。
3. 比较固定头在参考图和待查图上的热区是否随参考身份改变。
4. 若待查图中存在多个同类物体，重点检查热区是否从正确实例移向另一个实例。

**对照：** 不改变参考图、只重复运行同一输入。

**通过条件：** 输入相同参考图时结果稳定；换成错误身份后，模型行为和相关热区出现与身份变化一致的变化。

**失败意味着什么：** 这些头可能只负责普通物体定位，不能说明它们参与了 IPLoc-ID 的个体识别。

### 实验 8：移动一张图里的物体后，热区会跟着谁移动
**要回答的问题：** 热区是在跟踪真实物体，还是简单复制另一张图的坐标，或者总看固定位置？

**使用什么数据：** 从未用于选择注意力头的样本，对参考图或待查图单独做水平翻转、垂直翻转或受控位置移动。

**具体做法：**
1. 只变换参考图，待查图不变；检查参考图热区是否跟随物体移动，待查图热区是否保持合理。
2. 只变换待查图，参考图不变；检查待查图热区是否跟随物体移动。
3. 将变化后的热图还原到原坐标后，与原热图比较。
4. 同时比较三个解释：跟随参考图物体、复制待查图坐标、始终关注图像中心/边缘/底部。

**通过条件：** 热区主要跟随被变换图中的真实物体，而不是机械复制另一张图的坐标或停留在固定位置。

**失败意味着什么：** 固定头可能利用了位置规律，不能称为可靠的物体定位证据。

### 实验 9（最后才做）：关掉这些注意力头，模型是否真的变差
**要回答的问题：** 前八个实验找到的头只是能“读出”物体位置，还是模型完成任务确实需要它们？

**开始条件：** 只有实验 1–8 通过后，另行提交审核和执行授权。

**具体做法：**
1. 关闭固定注意力头对目标图像区域的关注，再运行 IPLoc-ID。
2. 关闭相同数量、来自相近模型层的随机头，作为公平对照。
3. 比较模型回答是否正确、预测框与真实框的重合程度，以及其他正常回答能力是否受损。

**通过条件：** 关闭固定头造成的任务下降明显大于关闭随机头，同时不是因为模型整体失去正常输出能力。

**失败意味着什么：** 这些头可以显示物体位置，但没有证据表明模型依赖它们完成 IPLoc-ID。

## 每次实验保持什么不变
- 使用同一个已经训练好的 IPLoc-ID 模型和同一份附加训练权重。
- 使用真实任务中的问题格式、图像处理方式和答案生成方式。
- 在正式检查结果前写死数据分组、选择多少个注意力头、如何把热图变成物体框。
- 同一视频序列或同一物体身份不能同时用于挑选注意力头和检查这些头。
- 参考图和待查图始终分开记录，模型答对和答错始终分开记录。

## 必须比较的其他方法
1. 随机挑选相同数量、来自相近模型层的注意力头。
2. 只挑“整体上经常看图”的注意力头。
3. 只挑“每张注意力图集中在少数位置”的注意力头。
4. 每张图片临时挑最有利的头。这只能作为理想上限，因为它不是一组固定的头。
5. 将所有注意力头平均。
6. 不使用模型注意力，始终猜图像中心、边缘或底部，用来检查是否只是位置规律。
7. 实验 9 中，关闭相同数量、来自相近模型层的随机头。

论文原方法会同时考虑“一个头花多少注意力看图”和“它的注意力是否集中”，再统计它在许多图片中被选中的次数。E-010 只比较这套选择方法在 IPLoc-ID 上是否优于上述方法，不复现 RefCOCO 分数。[[localizationheads2025]] §4.1–4.2、§6.3

## 正式实验前的小检查
1. 用少量样本确认参考图、待查图、文字位置和物体框正确对应。
2. 同一输入重复运行，确认得到相同的注意力头排名和热图。
3. 水平翻转一张图片，确认热图可以准确还原和比较。
4. 用一个很小的数据划分完整走通“先挑头、再锁定、最后检查”的过程，确认检查阶段不会重新挑头。
5. 人工检查固定数量的热图，但不能根据这些热图修改选择规则。

这些小检查只判断程序能否进入正式实验，不产生科学结论。

项目已有 E-005 结果可以提醒我们哪里容易出错，但不能代替本次实验：
- 之前用 100 个 IPLoc-ID 样本挑出了出现次数最多的 5 个头；名单固定后，在另外 40 个样本上生成的物体框几乎找不到目标：平均框重合比例约为 0.034，没有任何样本达到 0.5 的重合标准。这说明“经常被选中”不等于“真的会找物体”。
- 之前分别观察参考图和待查图时，选出的前 5 个头大多不同；少数编号相同的头也不一定真的看向物体。这说明不能只比较头的编号，还必须逐个检查它们是否看中了真实区域。

这些结果来自当前 Qwen3-VL/IPLoc-ID 路线，是重要的初步负面证据。但此前使用的数据划分、较低图像尺寸和多次后续调整不足以给出最终判断。本次实验必须提前写清数据分组、观察时刻和判断规则，之后不能根据结果重新改规则。

## 还要分别检查哪些版本
- 固定 3 个注意力头和固定 5 个注意力头分别报告；也可以展示头数变化的完整曲线，但不能看完检查数据后再选择最好的数量。
- 论文的选择方法、只看总注意力、只看热图集中程度、随机选择、所有头平均、逐图临时选择分别报告。
- 模型看完问题时、准备输出框坐标时、准备回答“是/否”时分别报告。
- 单个头、多个头合并、去掉排名第一的头后再合并分别报告，用来检查结果是否完全依赖一个头。
- 原始样本、错误参考身份、只变换参考图、只变换待查图、背景区域分别报告。
- 如果能取得模型训练时没有见过的视频序列或物体身份，单独报告；否则不得声称模型对未见身份具有泛化能力。

## 如何计算结果
- **名单是否稳定**：直接数不同实验中有多少个完全相同的注意力头，并比较完整排名是否接近。
- **单个头是否看对位置**：检查热图最强的点是否在真实框内；计算真实框得到的注意力，并除以真实框面积占整张图的比例。结果大于 1 表示它比均匀看整张图更偏向物体。
- **热图生成的框是否正确**：计算预测框和真实框的重叠面积，再除以两者合并后的面积。结果从 0 到 1，越大越好；同时报告重叠超过 0.3、0.5 和 0.7 的图片比例。
- **是否覆盖多数图片**：报告每张图有几个固定头看中物体、至少一个头看中的图片比例、多数头都看中的图片比例，以及表现最差的数据组。
- **变换后是否跟随物体**：先把变换后的热图还原到原图方向，再比较两张热图是否接近，以及热区中心和最强点移动了多远。
- **是否影响模型行为**：实验 9 比较关闭固定头和关闭随机头后，模型答对比例及预测框重合程度下降多少。

## 容易造成误判的因素
- 大物体天然会得到更多注意力，所以不能只看框内注意力总量，必须除以物体面积并与同样大小的背景比较。
- 一张很集中的热图也可能只看着背景、图像中心或边缘，不代表看到了目标物体。
- 不同尺寸图片会产生不同数量的图像小块；如果小块到原图的位置对应错误，所有热图结论都无效。
- 问题末尾的空格、换行和答案开头会改变“当前文字位置”，所以必须记录实际读取的是哪个文字符号。
- 每张图片临时选最有利的头会使用当前图片的信息，因此只能作为理想上限，不能证明固定头可靠。
- 同一视频的相邻帧很相似，若分到挑头数据和检查数据两边，会造成虚假的好结果。
- 反复尝试不同头数、阈值、文字位置和画框方法后只报告最好的一次，会造成不公平选择；这些设置必须提前固定。
## 还需要注意的风险
- **本实验不复现原论文：** 我们只检查论文的选头方法放到 IPLoc-ID 后是否可靠，不评价论文在 RefCOCO 上的结果是真是假。
- **模型可能见过这些数据：** IPLoc-ID 模型已经训练完成。如果测试视频或物体身份曾用于训练，只能说明“挑头数据”和“检查数据”之间能够复现，不能声称模型能处理训练时没见过的身份。若能取得训练外数据，必须单独报告。
- **平均值可能骗人：** 大物体、容易图片或模型答对的图片可能拉高平均值，所以逐张结果、答对/答错结果和最差分组必须作为主要结果。
- **参考图和待查图可能使用不同的头：** 这不一定是失败。真正的要求是，两边各自的头都能在换数据后重复找到，并在新图片上看中物体。
- **重新输入正确答案只能用于读取注意力：** 它不能替代模型自然生成的答案。每张注意力图必须和对应的自然答案一一配对，答错样本不能删除。
- **好看的热图不等于模型依赖它：** 只有实验 9 关闭这些头后模型明显变差，才能进一步讨论它们是否是模型完成任务所必需的。

## 如何合并执行

建议只建立 **2 个 Run**。9 个问题在 Run 内作为独立结果表和内部检查步骤，不再分别审批。

### Run 1：固定注意力头是否稳定、是否真的能找物体

**合并内容：** 实验 1–6。

**为什么可以合并：** 这些检查使用同一个 IPLoc-ID 模型、同一批自然生成答案和同一套注意力数据。模型只需加载一次；每张样本的注意力只需提取一次，之后更换挑头数据、比较名单、计算参考图和待查图结果都可以离线完成。拆成 6 个 Run 只会重复加载模型和重复审批，不会增加科学可信度。

**Run 内执行顺序：**
1. 先用少量样本确认参考图、待查图和文字位置对应正确。
2. 位置检查通过后，完成全部样本的自然答案和注意力提取。
3. 按视频序列或物体身份分组，多次更换挑头数据，检查名单稳定性。
4. 在完全没有参与挑头的样本上固定名单，检查能否找到物体。
5. 使用同一份结果分析多数图片覆盖情况，以及模型答对和答错时的差异。
6. 分别挑选和交换检查参考图用的头、待查图用的头。

**Run 内停止条件：**
- 第 1 步位置对应失败：立即停止，不产生任何注意力头结论。
- 名单稳定性不高于随机选择：仍完成已提取数据的离线汇总，但结论直接记为“不支持固定少数头”，不再为了得到稳定名单而修改规则。
- 固定头在未参与挑选的图片上不优于随机头：保留完整负结果，不追加新的挑头方法挽救结论。

**必须交付的独立结果：**
- 位置对应检查表；
- 多次更换数据后的注意力头名单和重合表；
- 未参与挑头图片上的逐张定位结果；
- 容易/困难图片及最差分组结果；
- 模型答对与答错的对比；
- 参考图和待查图各自的头及交换检查结果；
- 固定样本热图和全部失败样本清单。

### Run 2：排除错误解释，并检查模型是否真的依赖这些头

**合并内容：** 实验 7–9。

**依赖关系：** Run 2 的问题、数据来源、变换方法和判断标准可以现在一起写好，但实际使用的注意力头必须由 Run 1 按预先规则产出，并作为不可更改的输入传给 Run 2。Run 2 不得重新挑头。只有 Run 1 证明这批固定头在换数据后仍较稳定、并且在未参与挑选的图片上优于随机头，Run 2 才执行；否则直接取消 Run 2。

**为什么可以合并：** 换错参考身份、单独移动参考图或待查图、关闭固定头都需要重新运行模型，但使用相同样本、相同模型和相同固定头。它们可以在一次模型加载中依次完成，并共享未改变输入的重复运行结果作为对照。

**Run 内执行顺序：**
1. 对相同待查图换成同类别但错误身份的参考图，检查答案和热区是否变化。
2. 分别只变换参考图、只变换待查图，判断热区跟随物体、复制坐标还是停在固定位置。
3. 只有前两步没有发现明显的身份无关或固定位置问题时，才关闭 Run 1 的固定头，并与关闭相同数量的随机头比较。

**Run 内停止条件：**
- 如果换错参考身份后结果完全不变，记录“只支持普通物体定位，不支持个体识别”，但仍可执行空间变换检查，因为它回答的是不同问题。
- 如果空间变换显示热区主要复制坐标或停在固定位置，记录失败并停止关闭注意力头的步骤。
- 只有身份检查和空间检查都达到 Run 2 预先写定的标准，才执行关闭注意力头；这条条件写入同一个 Run 的规范，不另建第三个 Run。

**必须交付的独立结果：**
- 正确参考身份与错误参考身份的成对结果；
- 只变换参考图和只变换待查图的成对结果；
- 三种解释的直接比较：跟随真实物体、复制另一张图坐标、固定位置；
- 若内部条件通过，关闭固定头与关闭随机头的任务结果；若未执行，明确写出由哪条停止条件阻止，不记为缺失或零结果。

## 为什么不建议只做 1 个 Run

技术上可以把所有内容塞进 1 个 Run，但不建议：

- Run 2 必须使用 Run 1 已经固定且检查过的头；在同一个 Run 中边看结果边决定后续干预，更容易产生事后修改规则的问题。
- “读取和比较注意力”不会改变模型，而“关闭注意力头”会改变模型内部计算，两者风险和结论等级不同，分开审核更清楚。
- 如果 Run 1 已经证明固定头不稳定，Run 2 可以取消，避免不必要计算。

因此，**2 个 Run 是审批压力与科学边界之间更合适的折中**。

## 总体停止规则
当前只完成实验设计，不创建或启动 Run。正式登记时一次创建上述两个 Run 的草稿，但 Run 2 标明依赖 Run 1：

1. Run 1 先执行，选择规则、数据分组、注意力头数量和判断标准在看结果前固定。
2. Run 1 无论得到正结果还是负结果都完整归档，不允许通过更换规则重跑来挑选有利答案。
3. Run 1 只有同时通过“换数据后名单稳定”和“新图片上优于随机头”两项检查，Run 2 才执行；否则 Run 2 记为因前置条件失败而取消。
4. Run 2 使用 Run 1 自动导出的固定名单，不允许人工替换；其中关闭注意力头的步骤还受 Run 2 内部条件限制。
5. 两个 Run 各自只审批一次；Run 内的小步骤不单独建立 Run，但必须分别报告，不能只给一个总平均数。
