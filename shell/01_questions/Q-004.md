# Q-004 · E-003低IoU自然错误中，reference-retrieval与bbox-localization attention signature为何不一致？

## 编号与来源更正

原记录中的“E-004 R21b”应更正为：

```text
E005-R-021b-e003-screened-wrong-instance-natural-output-attention-n7
```

- 错误样本和自然输出来自 `E003-R-004b`；
- attention提取与可视化属于 `E-005 R-021b`；
- `E-004`仅在后续做activation patching/CMA等因果验证时相关，不能把当前heatmap称为E-004因果结果。

## 原始疑问（精确化）

在E003-R-004b中，部分positive样本自然输出`Yes`，但自然预测bbox与target GT的IoU低于0.1。R-021b对七个单人初筛的`screening_only_not_confirmed`案例（IDs `22,23,42,43,93,94,138`）使用冻结heads进行了三类attention诊断。

图中出现一个值得检验的表面不一致：

```text
GT-conditioned cross-image retrieval：
  query GT object visual rows
  → reference visual keys
  常在reference GT或其附近形成热点

natural bbox localization：
  归档自然bbox token p的p-1 rows
  → query visual keys
  常跟随红色错误预测框/另一同类实例

同一natural bbox rows → reference visual keys：
  有时落到不同reference实例、邻近同类对象或弥散区域，
  与GT-conditioned retrieval map并不一致
```

因此更准确的问题是：

> 当正确query-object tokens到reference target的attention path仍然存在时，模型为何会在自然bbox生成阶段把定位attention路由到另一query候选？这是reference–candidate绑定失败、输出阶段候选锁定、不同head角色的正常分工，还是由GT-conditioned probe和可视化方法造成的表象？

## R-021b中可见的初步现象

以下仅为七张固定图的人工观察，不是预注册定量结论：

1. `23/cattle`、`42/elephant`、`43/elephant`、`93/person`、`94/pig`、`138/zebra`中，query localization map的高值区域明显更接近红色自然预测框或其邻近实例，而不是绿色target GT。
2. 多个样本的GT-conditioned retrieval map仍在reference GT附近形成热点；这说明从**正确query-object rows**出发，reference target附近仍可出现空间选择性的attention连接。
3. natural bbox rows投向reference时，热点不总与上述retrieval map一致；在reference本身包含多个同类对象时，可能偏向另一个实例或更大的同类区域。
4. natural Yes decision maps继续表现为弱对象定位/非图像历史主导的signature，与R-019b的空间质量失败结论一致；它们不能用于判定到底选中了哪个实例。
5. 七例的224分辨率replay中，归档Yes相对No的logit margin均为正（`1.375–8.375`），但原生成分辨率为640，因此这里只能称`resolution-reduced archived-natural-output replay`。

## 当前最关键的解释边界

### 1. retrieval图是GT-conditioned、post-hoc的

R-021b的reference retrieval不是模型自然生成过程中显式产生的一个“正确目标选择步骤”。它使用query GT选取query-object visual rows，然后观察这些rows到reference keys的attention：

```text
query GT用于选择attention query rows
reference GT不参与map计算，只用于画框/空间审核
```

所以“retrieval map落在reference GT”只能支持：

> 从正确query-object tokens出发，冻结retrieval heads保留了指向reference object region的attention path。

不能升级为：

> 模型先正确识别了target，之后才莫名其妙改选wrong instance。

后一句需要自然生成轨迹、无GT row selection或因果干预才能支持。

### 2. 两张图使用不同query rows和不同head集合

当前比较并非同一attention算子的前后状态：

```text
retrieval：GT-selected query visual rows × retrieval heads
localization：natural bbox token p-1 rows × localization heads
```

两组有效heads没有exact-head overlap：

```text
retrieval = L17H00,L07H22,L02H05,L09H18
localization = L18H15,L19H03,L22H00,L20H08
intersection = ∅
```

因此空间图不一致可能反映角色分工，而不必然是内部矛盾。LocalizationHeads论文也只证明少量attention heads可承载grounding signal；raw attention及head ranking本身不构成因果机制。[[localizationheads2025]] §3–§4.2、§6.3。

### 3. reference/query中的其他同类实例未被完整标注

LaSOT这里只提供tracked target bbox。图像中其他牛、象、人、猪或斑马没有instance identity annotation。由此：

- 红框看似覆盖另一实例，不等于已正式确认wrong-instance；
- reference attention热点落到另一同类对象，也不能计算non-target hit；
- 需要全体同类实例bbox和identity/track correspondence后才能区分target、non-target、part、container与background。

该问题与Q-003的candidate-conditioned同图identity-binding评测缺口直接相关。

### 4. per-panel min-max不能比较绝对强度

R-021b每个panel独立min-max normalization。图只能比较**单个panel内部的空间位置**，不能据颜色深浅比较：

- retrieval比localization“更强”；
- reference比query使用更多；
- 错误样本比正确样本attention总量更高。

这些必须从raw attention mass计算。

## 可竞争解释

### H1：candidate lock-in / localization routing failure

正确query-object rows仍能检索reference target，但自然生成bbox时，localization heads锁定了另一query候选；后续Yes decision没有纠正该候选。

可证伪预测：错误样本中，localization heads对`predicted box`的concentration显著高于对`target GT`，且这种`predicted-minus-target`偏置显著强于matched-correct controls。

### H2：reference–candidate binding failure

natural bbox rows在query上指向预测候选，同时在reference上指向与retrieval heads不同的同类实例，形成错误的跨图像对应关系。

可证伪预测：在拥有reference/query全实例标注的数据中，bbox rows对reference non-target的mass高于reference target，并与query predicted non-target形成稳定配对；仅看当前单目标GT不能验证。

### H3：角色分工而非失败

retrieval heads负责object-region cross-image lookup，localization heads负责输出坐标；两组head空间分布不同是正常模块分工，真正错误发生在更早或更晚的位置。

可证伪预测：matched-correct样本中也存在同等程度的retrieval/localization map差异；差异大小不能区分error和correct。

### H4：GT-conditioned probe artifact

只要从任何正确object rows出发，retrieval heads都会落到reference同类区域；这并不表示identity-selective retrieval。R-018中positive与same-class negative差异不稳定，已支持这一风险。

可证伪预测：用same-class non-target query rows或negative object rows时，reference-target concentration与GT-target rows近似，且positive-minus-negative不稳定。

### H5：尺度、token-grid与可视化混淆

小reference box在224 replay后可能只覆盖极少merged tokens；Gaussian smoothing、粗grid和panel内归一化可能让热点看似落在邻近实例。

可证伪预测：提高可行分辨率、报告selected-token count并在raw grid上复现后，现象显著减弱或消失。

## 待检验主假设

> E-003 accepted-low-IoU错误可能不是“完全没有reference信息”，而是正确object-conditioned reference path与自然bbox生成所采用的candidate-localization path发生了路由不一致；模型随后仍输出Yes，未对candidate与reference identity的一致性进行有效纠正。

status：`investigating / inference_only`。

该表述当前不能进入validated综合。尤其不能写成“已发现identity-routing circuit”或“已证明模型先认对再框错”。

## 判定实验A：冻结规则的error vs matched-correct定量比较

### 样本

```text
error：R-004b positive + identification=Yes + IoU<0.1，主集合n=35
priority error：IDs 22,23,42,43,93,94,138，仅单列展示
correct：positive + identification=Yes + IoU>=0.7
```

在读取attention结果前，按以下变量为每个error匹配correct：

```text
class（能同类则同类，否则记录不可匹配）
query GT box area fraction
reference GT box area fraction
merged token count
query/reference aspect ratio
```

不能按heatmap好坏挑对照。

### 冻结heads与位置

```text
retrieval heads：L17H00,L07H22,L02H05,L09H18
localization heads：L18H15,L19H03,L22H00,L20H08
decision control：L03H20,L04H29,L10H29,L12H21
```

保持autoregressive alignment：token `p`由row `p-1`预测。

### Raw-attention指标

对每个map均保存raw mass，禁止只分析min-max图：

1. **Reference target enrichment**
   ```text
   E_ref_target = attention density in reference GT /
                  attention density outside reference GT
   ```
2. **Query target enrichment**：localization map对query GT的density enrichment。
3. **Query predicted-box enrichment**：localization map对归档自然预测框的density enrichment。
4. **Candidate-lock score**
   ```text
   CLS = log(E_query_pred + eps) - log(E_query_GT + eps)
   ```
   error中预期为正；correct中GT与pred高度重合，需另报告二者交集并避免重复解释。
5. **Reference-role discrepancy（仅诊断）**
   ```text
   RRD = log(E_ref_target_retrieval + eps)
         - log(E_ref_target_bbox_rows + eps)
   ```
   它比较不同rows/heads，只能作为group-level signature差异，不能称时间上的信息丢失。
6. **Decision visual budget**：Yes row到reference、query和other-history的raw mass比例。
7. **Token-grid完整性**：每个GT/pred bbox覆盖的merged token count；0或极少token样本单列，不混入主统计。

统计以sample为单位做paired bootstrap，报告median difference和置信区间，不只展示七张图。

### 判定实验A2：reference目标绑定的四状态频率（预注册建议）

用户提出进一步比较：correct中，自然bbox阶段的query-localization heads投向reference时，是否比error更常与reference GT以及reference-grounding heads保持一致。为避免直接要求两张角色不同的raw heatmap逐像素相同，主分析采用**目标区域绑定事件**。

同一forward、同一reference merged-token grid上构造：

```text
Q→R map：natural query bbox token p-1 rows
         × query-localization heads
         → reference visual keys
         heads=L18H15,L19H03,L22H00,L20H08

G→R map：prompt中reference bbox token p-1 rows
         × reference-grounding heads
         → reference visual keys
         heads=L15H13,L16H23,L18H15
```

两类map使用不同rows/head集合，故只检验是否共同绑定reference target，不解释为同一电路或时间上的信息传递。使用raw、未平滑attention；Gaussian和panel min-max只用于图。

对每张map定义严格target-hit：

```text
H(map)=1 iff
  GT density enrichment > 1
  AND raw-map argmax merged token overlaps reference GT
  AND reference GT overlaps >=2 merged tokens
```

`<2` token样本不悄悄并入主频率，单列为low-coverage，并做`enrichment>1`的宽松敏感性分析。每个样本形成四状态：

```text
(H_G, H_QR)
11 = grounding与natural-bbox→reference均命中target（target-consistent）
10 = grounding命中、natural-bbox→reference未命中（routing mismatch）
01 = grounding未命中、Q→R命中（grounding-head异常/角色差异）
00 = 两者均未命中
```

主要报告：

```text
Target-consistent frequency:
  P(11 | correct) vs P(11 | error)

Routing-mismatch frequency:
  P(10 | error) vs P(10 | correct)

Conditional binding frequency:
  P(H_QR=1 | H_G=1, correct)
  vs
  P(H_QR=1 | H_G=1, error)
```

这三个频率比raw-map cosine/L2更符合“是否绑定同一reference target”的研究问题。统计使用预先冻结的35个matched pairs：报告分子/分母、Wilson区间、paired bootstrap差异；二元`11 vs non-11`和`10 vs non-10`可补充matched-pair McNemar exact test。由于当前仅约1个same-class matched pair，必须同时报告geometry covariates，并把class mismatch列为限制。

次要连续指标保留但不作为主判定：

```text
log E_QR(target)
log E_G(target)
min(log E_QR, log E_G)       # 双方target concentration的保守下界
2-bin target/outside JSD     # 只比较target-vs-outside预算，不比较像素坐标
```

可视化按预冻结pair输出：reference clean+GT、G→R map、Q→R map；correct/error各自一inference一图。禁止用top-k map overlap或pixelwise L2作为主指标，因为角色head可能在同一目标的不同部位形成热点。

该A2需要新的同forward提取run；现有R-022系列已提取`Q→R`但未按上述冻结reference-grounding heads保存逐样本`G→R` raw map，不能事后伪造完整A2统计。

## 判定实验B：全实例标注后的错误类型确认

对35个error query和其reference frame标注：

```text
所有same-class instances
tracked target
可确认的non-target实例
object part / group / container / background
遮挡与出界
```

定义：

```text
wrong-instance hit：target IoU<τ 且某non-target IoU>=τ
part/container/background：按预注册taxonomy
```

只有这一步后，才能检验bbox-row attention是否同时连接：

```text
query predicted non-target ↔ reference target/non-target
```

七个旧案例继续保留`screening_only_not_confirmed`，不得因attention热点而自动升级标签。

## 判定实验C：无GT选择的自然检索轨迹

为排除GT-conditioned artifact，应增加不使用query GT选rows的自然变体，例如：

1. 在自然bbox生成前的文本query rows上读取到reference/query visual spans的attention；
2. 从自然高响应query visual rows出发，而不是GT object rows，检查其reference落点；
3. 对所有query visual rows计算到reference target的retrieval score，再看模型自然选中的query区域；
4. 所有variant必须单独命名并重新做GT spatial quality gate，不能直接沿用R-018结论。

## 判定实验D：因果验证（归入E-004）

若A/B/C显示稳定的error-specific routing mismatch，再做：

```text
source：matched-correct或target-consistent trajectory
base：accepted-low-IoU natural trajectory
干预：冻结retrieval/localization head输出的source→base patching
结果：自然bbox token likelihood、target-vs-wrong candidate likelihood、Yes/No margin
```

并比较：

```text
只patch retrieval heads
只patch localization heads
联合patch
matched random heads
```

只有patching能稳定把错误候选转向target，才可讨论因果routing作用。attention map本身不能替代CMA/MF。

## 当前判断

1. **现象值得保留**：七例中确有“GT-conditioned reference retrieval仍较像target，但natural bbox localization在query上跟随错误候选”的可视模式。
2. **最强安全解释**：正确query-object tokens到reference object region的attention path可以与错误bbox-generation localization signature共存。
3. **尚不能解释为**：模型先正确识别target、随后身份切换；reference head与query head互相冲突；或已发现wrong-instance causal circuit。
4. **最高优先级缺口**：完成35个error与预先匹配correct的raw-attention定量比较，并补全同图实例annotation。
5. **与Q-003关系**：Q-003讨论benchmark是否覆盖candidate-conditioned同图identity binding；Q-004进一步问自然错误中是否存在可测的retrieval–localization routing mismatch。
