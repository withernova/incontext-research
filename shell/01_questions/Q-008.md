# Q-008 · 0902-实验瓶颈

## 原始疑问

目前的实验对mIoU几乎没有正向帮助

## 当前判断


> Dynamic 蒸馏确实让 Query Top-5 与 Reference Top-3 显著对齐，但这种 attention 对齐与最终 bbox IoU 改善没有稳定相关性；同时 Reference teacher 本身发生了明显漂移。

这比简单说“性能没提升”更准确。

## 1. Dynamic 训练已完成

```text
495 / 495 steps
status = passed
finite_grad_fraction = 1.0
adapter_delta_norm = 5.4528
```

训练过程中：

```text
dynamic auxiliary loss:
约 0.0800 → 0.0155

shape KL:
约 0.800 → 0.154
```

所以蒸馏目标本身确实被优化了，并不是 loss 没起作用。

## 2. 正式自然生成性能

Combined test 的结果：

| 模型 | mIoU |
|---|---:|
| step1729 | 0.693467 |
| continued-SFT baseline | 0.694364 |
| dynamic teacher | 0.689856 |

差值：

```text
dynamic - step1729 = -0.003611
dynamic - baseline = -0.004508
```

逐样本相对 step1729：

```text
改善：733
退化：765
不变：268
```

说明 dynamic 不是所有样本一起小幅下降，而是有明显的正负抵消，退化略多。

## 3. Head 重新检测发现 teacher 漂移

在完全相同的 `valid96` 上重新进行全 head screening。

### step1729 Reference Top-5

```text
L20H20
L20H15
L14H23
L16H09
L18H12
```

其中前三个正是原来的 Reference teacher：

```text
L20H15, L20H20, L14H23
```

### Dynamic final Reference Top-5

```text
L17H04
L20H15
L21H10
L17H07
L24H16
```

这里除了 `L20H15`，其余多数都是原 Query student heads：

```text
L17H04
L21H10
L17H07
L24H16
```

原 Reference teacher 中：

```text
L20H20
L14H23
```

已经跌出 Reference Top-5。

这说明 dynamic 训练过程中虽然 teacher target 做了 `detach()`，但 Reference heads 仍然通过：

- SFT loss；
- 共享 student 上游路径；
- 共享 LoRA projection；

发生了明显变化。

所以实际过程不完全是：

```text
稳定老师逐渐更新
→
学生跟随老师
```

更像是：

```text
teacher 和 student 共享网络后共同重组，
student 最终非常接近当前 teacher，
但 teacher 的原有排序和功能不再稳定。
```

## 4. Attention 对齐确实变强

同一 `valid96`、同一 teacher-forced bbox token rows：

| 指标 | step1729 | Dynamic final |
|---|---:|---:|
| Teacher→Student KL | 0.7776 | 0.1713 |
| Student object mass | 0.00701 | 0.00927 |
| Student S50-fIoU | 0.1479 | 0.2956 |
| Teacher object mass | 0.00385 | 0.00571 |
| Teacher S50-fIoU | 0.2637 | 0.2598 |

主要观察：

1. Teacher→Student KL 下降约 78%，说明对齐非常成功；
2. Student S50-fIoU 几乎翻倍；
3. Student 对 Reference GT object 的 mass 有所增加；
4. 但 Teacher 自身的 S50-fIoU 没有变好：
   ```text
   0.2637 → 0.2598
   ```

所以：

> Student 学会了当前 teacher 的 attention 形状，但 teacher 本身并没有变成更好的目标区域读取器。

## 5. 对齐指标与最终 IoU 改善基本无相关性

我计算了 valid96 上每条样本的自然生成 IoU delta 与 attention 指标之间的 Spearman 相关。

```text
Dynamic KL vs IoU delta:
rho = 0.089, p = 0.391

Teacher object mass vs IoU delta:
rho = -0.005, p = 0.963

Student object mass vs IoU delta:
rho = -0.125, p = 0.226

Teacher S50-fIoU vs IoU delta:
rho = -0.014, p = 0.892

Student S50-fIoU vs IoU delta:
rho = -0.044, p = 0.667
```

均没有显著关系。

也就是说：

```text
teacher/student 对齐更好
```

并不可靠地意味着：

```text
自然生成 bbox 更准确
```

这是当前最重要的负面诊断。

## 6. 错误样本可视化观察

### 显著退化：hand-10

```text
IoU: 0.682 → 0.037
KL:  0.451 → 0.096
```

Dynamic 后 teacher 和 student 都更加集中在 Reference 手部，attention alignment 明显变好。

但 Query 中模型从原本接近正确手的位置，跳到了另一只手：

```text
attention 对齐正确
但实例对应关系错误
```

这说明 Reference object reading 解决不了 Query 图中多个相似候选实例之间的选择问题。

### 显著改善：coin-12

```text
IoU: 0.000 → 0.969
KL:  0.786 → 0.192
```

这里 dynamic student 更集中于 Reference 中目标硬币，并且 Query bbox 从错误硬币切换到了正确硬币。

这是方法理想生效的案例：

```text
Reference 目标读取改善
→
Query 实例选择改善
```

### 持续失败：basketball-16

```text
IoU: 0 → 0
KL:  1.220 → 0.226
```

尽管 teacher/student 对齐明显改善，但 Query 仍选错目标。

该场景存在：

- 多个人；
- 多个篮球；
- 小目标；
- Reference bbox 很小；
- Query 中目标尺度和位置变化明显。

这说明单纯对齐 Q→Reference map 不足以完成：

```text
Reference appearance
→
Query 候选实例绑定
```

它只是提高了“看 Reference 的一致性”，没有直接约束“在 Query 中找对应对象”。

## 7. 逐 head 结果

Reference teacher 中真正强的主要是 `L20H15`：

```text
L20H15 object mass:
0.00974 → 0.01504

L20H20:
0.00116 → 0.00151

L14H23:
0.00064 → 0.00059
```

三个 teacher head 质量很不均衡：

- `L20H15` 很强；
- `L20H20` 相对弱；
- `L14H23` 很弱且高熵。

Student 中变化最大的是：

```text
L21H10 object mass:
0.00422 → 0.01514
entropy:
3.45 → 2.62
```

它非常明显地学到了 `L20H15` 式的集中 attention。

但：

```text
L17H04 entropy:
3.54 → 4.81

L17H07 entropy:
4.12 → 4.86
```

这两个 head 反而变得更弥散。

因此 Top-5 ensemble 的改善并不是五个 head 都一致变好，而主要由少数 head 驱动：

- `L21H10` 明显增强；
- `L24H16` 有所增强；
- `L17H04/L17H07` 变得更弥散；
- ensemble 平均掩盖了 head 间差异。

## 9. 我对下一步的判断

不建议简单地继续加大 alignment coefficient。因为当前已经证明：

```text
alignment loss 显著下降
```

但：

```text
held-out bbox 性能没有上升
```

加大系数很可能只会让 heads 更相似，而不是解决 Query 实例选择。

更合理的下一步有两个方向。

### 方向 A：稳定 teacher

动态 teacher 漂移是当前明显问题。可以改为：

```text
EMA teacher LoRA
```

或：

```text
固定 Reference teacher + 当前 student
```

但 fixed teacher 正是原来的 correct，因此应先看 correct 的正式结果，不能只根据 dynamic 下结论。

### 方向 B：加入 Query-side 对应约束

错误案例显示最大问题是：

```text
模型知道 Reference 中目标是什么，
但仍在 Query 中选错相似实例。
```

因此更直接的辅助目标应该包含：

```text
Q bbox rows → Query GT object span
```

或者：

```text
Reference object representation
↔
Query object representation
```

而不是只优化：

```text
Q bbox rows → Reference visual span
```

## 结论

应该做 head 检测和错误样本可视化，而且结果已经说明：

> Dynamic 蒸馏在机制层面成功实现了 Reference→Query head alignment，但该 alignment 不是充分的 localization 机制。Teacher 排名发生漂移，Student ensemble 由少数 heads 驱动，并且更低的 teacher–student KL 与自然生成 IoU 改善没有显著关系。当前主要瓶颈更像是 Query 图中的对应实例选择，而不是“有没有读取 Reference 目标”。
