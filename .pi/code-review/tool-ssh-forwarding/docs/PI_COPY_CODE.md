# Pi 原始代码块复制

安装组件后，在 Pi 中 `/reload`，然后输入 `/copy-code`。选择最近助手回复中的代码块，再选择原样复制、Bash 单行复制或编辑后复制。`/copy-code 1` 直接选择最近回复的第一个代码块。只读取当前会话分支中的助手正文，不读取 thinking、工具结果或其他分支。

原样复制保留真实换行，不带终端软折行和界面边框。Bash 单行复制仅删除引号外明确的反斜杠换行，保留其他字符，不添加空格，也不附加末尾换行。跨行引号、heredoc、注释、命令替换、不明确的断行或未完成续行会拒绝转换，需使用原样复制或编辑。插件不执行命令，也不会猜测拼接被截断的路径。

例如 checkpoint 中的 `20260907T174853785543Z--focus-early-gt-mask-pipeline` 必须是一个连续路径片段；反斜杠续行后不能插入空白行。若助手的原文已经包含这些错误，复制功能无法恢复丢失的结构，会提示检查原文。

剪贴板使用当前 Pi 导出的 `copyToClipboard`，沿用其平台工具和 OSC 52 支持。终端若不支持剪贴板转发，发送不代表系统剪贴板一定更新；应先粘贴到编辑器核对。原样复制保留末尾换行，是否触发 shell 执行取决于接收终端的 bracketed paste 行为。

回归：`node tests/test_copy_code.js`。
